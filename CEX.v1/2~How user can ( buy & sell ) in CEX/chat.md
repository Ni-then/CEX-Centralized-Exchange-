# 💱 How user can buy and sell in CEX

## 🔄 Steps

1> **Deposit INR** (UPI/bank transfer se exchange mein INR deposit krdo , now we have INR balance)

2> **INR --> USDT** (Stable coin)

3> **Trade**

4> **Withdraw** : profit ke baad wapis USDT ==> INR krke bank meh nikal lo
